## Description

StudySpot is a full-stack web application built around a Flask REST API that helps users discover and review places to study, which includes libraries, cafés, and campus buildings. 

Users can browse study locations, search and filter spots, view detailed information about each location, submit and manage reviews, and save their favorite study spots. 

Each study spot can include ratings and information related to factors like noise level, seating, outlets, Wi-Fi, food, opening hours, parking, and available amenities.

The application also includes administrator functionality for managing users and study locations. 


## Features

- User registration & login
- User & admin roles
- Browse, search, & filter study spots
- Detailed place information & amenities
- Reviews & multi-category rankings
- Favorites
- User profile management
- Admin management for users & places
- Full CRUD functionality
- Audit logging
- Seeded relational database
- Prometheus/Grafana monitoring & backend alerting
