# Study Spot Finder

**Contributors**: Lucy Lerma, Mehrin Meher, Vivian Zhao 

## Description

This application helps users find and review places to study, including libraries, cafés, and campus buildings. Users can rate study spots based on factors such as noise level, seating, outlets, Wi-Fi, food, opening hours, and parking. 

Users can add and browse study locations, submit and manage reviews, and save their favorite study spots. 


## Features

- User Management
- Study Spot Management
- Reviews & Ratings
- Search & Browsing
- Favorites
- Location Data
